# Shared frontend rules (optional CLAUDE.md snippet)

- Follow existing repository conventions, installed framework versions, and package manager scripts. Read applicable `README.md` documentation when a task needs it.
- Keep scope to the approved plan. Preserve other people's uncommitted changes; never commit, push, or modify dependencies without an explicit request.
- For shared library changes, consider public API compatibility, client themes, responsive layouts, and relevant consumers.
- Prefer targeted source searches and focused test output. Run mandatory repo checks; distinguish introduced failures from baseline/environment failures.
- Keep handoffs short: task and acceptance criteria going in; changed paths, checks, and reproducible findings coming out.
